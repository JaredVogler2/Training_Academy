# PHASE 17 — Comprehensive polish, truthful handoff and expansion plan

Read every previous prompt, all evidence documents and the actual app, not just checklist status. The goal is an unusually polished browser game that is educationally coherent, fast, safe and delightful.

## Polish pass
- Replace residual scaffolds, temporary icons, generic cards and dead ends in **released** modules with production art/animation; maintain a clear 'not available yet' label for unfinished extras.
- Audit first 30 seconds for a genuine preschooler: no reading, no prior letter-sound recognition, no account setup, no inaccessible permissions and a pleasurable task almost immediately.
- Audit instruction replay, conceptual error feedback, mixed evidence, reviews, safe exits, cancellation/reload, and accessible silent mode.
- Art-directed distinct mini-worlds with consistent character system, lighting, proportions, world reactions and sound design. Prioritize concentrated quality, avoiding content sprawl.
- Instrument privately on-device via a parent diagnostics view: render tier, FPS distribution if measured, session errors and content version; never transmit child behavior.
- Run 3+ structured adult-observed child playtest sessions if practical and consented; do **not** claim real child testing if not done. Record confusion, incorrect interpretations, difficulty and interest without recording or uploading faces/voices.
- Add lesson content only when it satisfies prerequisite, content review, localization, artwork, audio and testing requirements.

## Deliver final evidence
- A real playable complete path for all five flagship modules and the finished supporting modules; no misleading promise that optional rooms are complete.
- A module matrix: starting prerequisite, sample lessons, coverage, independent-mastery definition, number of tested challenges, performance evidence, known flaws.
- Visual report: screenshot links and scores across all viewports, **actual** render pipeline, assets and license attribution.
- Operational readiness: tested Vercel preview URL if available, exact production deployment status, rollback plan, responsible browser support claims, privacy overview and known limitations.
- Clean README for a parent and separate developer onboarding; public-friendly explanation of how learning evidence works without cognitive/medical claims.
- docs/CONTINUE_HERE.md: exact tested state, commit, open blockers and prioritized next 5 improvements.
- Plan future modules in order of value, with scope and real dependencies: Spanish dialogue, beginner chess, astronomy, advanced spatial rotation and parent-authorable story packs.
