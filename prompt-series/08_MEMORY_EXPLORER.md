# PHASE 08 — Memory Explorer: playful recall strategies

Create a lush hidden-object forest with richly illustrated, thematically linked objects and short sessions. Avoid claiming that game performance measures or universally increases IQ, attention span or general memory capacity.

## Curriculum
E0: match two illustrated objects with all cards face up; establish interface.
E1: hide and recall 2–4 objects, progressively vary layouts and icons, visual recognition before recall.
E2: recall both objects and *order* (e.g. five animals crossing a bridge).
E3: explicitly model a strategy: group items into categories, create a silly narrative, or link a journey through familiar scenes.
E4: give child a strategic choice (group/story/location), then test recall with and without the chosen hint.
E5: increase difficulty cautiously, offer delayed recall/review in another short session and transfer to distinct object sets.

## Fair assessment
Separate recognition vs serial recall vs cued recall vs unaided recall, and separate delay length; never mix these metrics into a global cognitive score. Hide/reveal should be deterministic and avoid accidental information leaks. Randomize identities, positions and response order to prevent solving via memorized layout. Don't artificially escalate to 15 objects unless the child enjoys the task and consistently demonstrates readiness.

## Sensory quality
Premium animated cards with clear silhouettes and shadows, smooth flip/reveal animations, audio names where appropriate and explicit demonstration. Motion reduction option; no flashing or elaborate failure animation. For storytelling strategies, display a pictorial connection rather than requiring verbal typing.

## Tests/acceptance
Prove cues are not scored as unaided, no hidden-object state remains exposed through UI, prompt order is correctly verified, and delayed recall works after reload. Test repeated seeds, responsive grids, keyboard and phone. Include an authored short lesson for *each* of the three strategies and explain to parent what was practiced. Commit.
